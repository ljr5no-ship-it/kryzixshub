This is the client, not the machine. CloudMoon streams a real Android box over WebRTC — a web page can only ever be the screen and the controls for one. So: deploy/ brings up Redroid, ws-scrcpy and Caddy on a VPS you own, plus a small control service so the buttons on this page run real adb commands. Point the host field at that domain and everything here goes live. See HOSTING.md for what that costs — the arcade itself hosts free.
